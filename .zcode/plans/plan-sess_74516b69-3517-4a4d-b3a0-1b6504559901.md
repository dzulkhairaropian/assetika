## Overview

## Urutan Field & Struktur Card Baru (`admin/lookups/form.blade.php`)

### 1. Left Main Column (`space-y-6`)
**Card: General Information** (`rounded-2xl border border-gray-200 bg-white p-5 dark:border-gray-800 dark:bg-white/[0.03] md:p-6 space-y-6`)
- Header: `<i data-lucide="info"></i> General Information`
- **Grid Layout (`grid grid-cols-1 gap-x-6 gap-y-5 lg:grid-cols-2`)**:
  1. Row 1: `Name` (Label: `Status Name *` / `[Title] Name *`) & `Code`
  2. Row 2: `Icon (Lucide Icons)` dengan input `id="status-icon"` & pill icon Lucide.
  3. Row 3: `Color (Hex / Theme)` dengan input `id="status-color"`, `id="color-picker"`, placeholder `e.g., #10b981 or success`, dan swatch warna.
  4. Row 4: `Sort Order`
  5. Row 5: `Description` (textarea `rows="3"`, full width `lg:col-span-2`, placeholder `Enter description`).

- Jika terdapat bidang khusus SLA (seperti pada SLA Statuses):
  **Card: SLA Settings** (`clock` header).

### 2. Right Sidebar (`space-y-6`)
- **Card: Status Options** (`settings` header):
  - Checkbox `Active` & Checkbox `Closed Status` (jika berlaku).
- **Card: Actions** (`save` header):
  - Tombol `Create Status` / `Update Status` (bg-brand-500)
  - Tombol `Create & Create New` (border-brand-500)
  - Tombol `Cancel` (border-gray-300)
