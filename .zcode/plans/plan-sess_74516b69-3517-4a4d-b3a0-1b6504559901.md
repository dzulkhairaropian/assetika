# Implementation Plan: Equalize Ticket Statuses Form & Index UI to match Asset Statuses

## Overview
Menyelaraskan seluruh halaman CRUD **Ticket Statuses** (dan Lookup Admin lainnya: Priorities, SLA Statuses, Ticket Types, Sources, Labels) di `admin/lookups/form.blade.php` dan `admin/lookups/index.blade.php` agar secara visual dan struktural **identik 1:1** dengan **Asset Statuses** (`pages/master/statuses/*`).

---

## Rincian Perubahan

### 1. Unified Form Layout (`resources/views/admin/lookups/form.blade.php`)
- **Struktur Layout 2-Kolom**: Menggunakan `grid gap-6 xl:grid-cols-[minmax(0,1.75fr)_380px]`.
- **Card Container**: `rounded-2xl border border-gray-200 bg-white p-5 dark:border-gray-800 dark:bg-white/[0.03] md:p-6`.
- **Section Headers**: Header bertingkat dengan icon Lucide (`info`, `palette`, `settings`, `save`).
- **Color Theme & Hex Swatches**: Menambahkan tombol pilihan cepat tema warna (`primary`, `secondary`, `success`, `danger`, `warning`, `info`, `light`, `dark`) beserta preview warna hex swatch persis seperti di Asset Statuses.
- **Interactive Icon Picker**: Pill button Lucide icons yang dapat diklik langsung mengisi input `icon`.

### 2. Unified Index Table Layout (`resources/views/admin/lookups/index.blade.php`)
- **Tabel & Checkbox**: Standardized rounded container, checkbox select-all per baris, dan badge status warna.
- **Filter Tabs**: Tab status keaktifan (`All`, `Active`, `Inactive`).
- **Bulk Action Bar & Modal**: Tombol **Bulk Edit (Change Selected)** yang membuka pop-up modal untuk mass-update `is_active` dan `color`.
- **Dropdown Actions Menu**: Tombol titik tiga (`more-vertical`) dengan menu Edit & Delete di setiap baris.
