# Implementation Plan: Uninstall `feather-icons` & Migrate Fully to `lucide-icons`

## Overview
Migrasikan seluruh sistem ikon dari **`feather-icons`** ke **`lucide-icons`** (yang sudah ada di `package.json`). Seluruh tombol akan dilengkapi dengan ikon Lucide yang sesuai, dan status checklist/konfirmasi menggunakan ikon **`circle-check`**.

---

## Steps & File Changes

### 1. Dependency & JS Setup
- **`package.json`**: Jalankan `npm uninstall feather-icons`.
- **`resources/js/app.js`**:
  - Hapus import `feather-icons`.
  - Import `createIcons` dan `icons` dari `lucide`:
    ```javascript
    import { createIcons, icons } from 'lucide';
    window.createIcons = createIcons;
    window.lucideIcons = icons;
    ```
  - Panggil `createIcons({ icons })` pada saat DOM ready.
- **`resources/js/ticket-charts.js`**: Update pemanggilan `window.feather.replace()` menjadi `window.createIcons({ icons: window.lucideIcons })`.

### 2. Blade Component Updates
- **`resources/views/components/ui/badge.blade.php`**:
  - Update `featherIcon` prop agar merender `<i data-lucide="{{ $featherIcon }}" class="w-3 h-3 shrink-0"></i>`.
- **`resources/views/components/metric-card.blade.php`**:
  - Update rendering ikon menggunakan `<i data-lucide="..."></i>`.

### 3. Replace `<i data-feather="...">` with `<i data-lucide="...">` in All Blade Views
- Ganti atribut `data-feather` menjadi `data-lucide` di seluruh file template Blade (`resources/views/**/*.blade.php`).
- **Ganti Ikon Check/Checklist**:
  - Gunakan `circle-check` untuk status/opsi checklist/konfirmasi (seperti pada badge completed, checkin/checkout success, checklist item).
- **Penambahan Ikon Tombol**:
  - Pastikan setiap button (Create, Edit, Delete, Save, Cancel, Export, Import, Filter, Checkin, Checkout, Maintenance, Retire, Submit) memiliki ikon Lucide yang jelas.

---
