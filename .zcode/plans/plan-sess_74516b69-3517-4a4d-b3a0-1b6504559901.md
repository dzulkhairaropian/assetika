# Plan Implementasi: Status Checkbox Laptop Kosong (Komponen RAM/SSD Dicabut) - Tanpa Link Inventory

## Overview
Menambahkan atribut `is_components_stripped` (boolean) pada tabel asset untuk menandai apakah unit laptop yang rusak (Broken), pensiun (Retired), atau diproses check-in sudah dalam keadaan **kosong / komponen RAM & SSD telah dicabut**, tanpa terhubung ke modul stok inventory.

---

## Rincian Perubahan

### 1. Database Migration & Model (`Asset`)
- **Migration**: Buat migration baru `add_is_components_stripped_to_assets_table` menambah kolom `is_components_stripped` (boolean, default: `false`, nullable).
- **Model (`App\Models\Asset`)**:
  - Tambahkan `is_components_stripped` ke `$fillable` dan `$casts => ['is_components_stripped' => 'boolean']`.

### 2. Form Check-in Asset (`AssetManagementController` & `checkin.blade.php`)
- **View (`checkin.blade.php`)**:
  - Tambahkan checkbox di bawah opsi status/kondisi check-in:
    `[ ] Komponen Dicabut / Laptop Kosong (RAM & SSD sudah dilepas)`
  - Saat status yang dipilih adalah *Broken* atau *Retired*, checkbox otomatis dicentang secara default (menggunakan Alpine.js / script bawaan).
- **Controller (`AssetManagementController@processCheckin`)**:
  - Update `is_components_stripped` pada instance `$asset` berdasarkan input checkbox form (`$request->boolean('is_components_stripped')`).

### 3. Form Edit & Create Asset (`AssetController` & `pages/assets/edit.blade.php` / `create.blade.php`)
- **View (`edit.blade.php` & `create.blade.php`)**:
  - Tambahkan field input checkbox `is_components_stripped` di bagian spesifikasi/informasi teknis asset.
- **Controller (`AssetController@store` & `update`)**:
  - Simpan nilai `is_components_stripped` ke database.

### 4. Tampilan Indicator & Badge Asset (`pages/assets/show.blade.php` & `index.blade.php`)
- **Detail Asset (`show.blade.php`)**:
  - Tampilkan badge status khusus jika `is_components_stripped == true`:
    `<span class="badge">Komponen Dicabut (Kosong)</span>` di samping badge status utama atau di section Technical Specifications.
- **Daftar Asset (`index.blade.php`)**:
  - Tampilkan icon/badge penanda kecil "Stripped / Kosong" jika laptop dalam keadaan tanpa komponen RAM/SSD.

---

## Flow Kerja Ringkas
1. User membuka form **Check-in Asset** atau **Edit Asset**.
2. User memilih status `Broken` / `Retired` atau mencentang manual `[✓] Laptop Kosong (RAM & SSD sudah dicabut)`.
3. Sistem menyimpan flag `is_components_stripped = 1`.
4. Halaman Detail & Index Asset menampilkan badge status bahwa laptop dalam kondisi **Kosong / Komponen Dicabut**.
