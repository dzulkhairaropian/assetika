# Implementation Plan: Update Ticket Statuses & Admin Lookups (Bulk Edit & Standardized Table UI)

## Overview
Menyesuaikan halaman **Ticket Statuses** (dan Lookup Admin lainnya: Priorities, Types, SLA Statuses, Sources, Labels) di `admin/lookups/index.blade.php` agar persis seperti **Asset Statuses**:
1. Fitur **Bulk Edit (Ganti Sekaligus)**: Memungkinkan memilih beberapa status ticket sekaligus untuk diubah warnanya (`color`) atau status aktifnya (`is_active`).
2. **Filter Tabs (All / Active / Inactive)**: Menambahkan tab quick filter status keaktifan di atas tabel.
3. **Standarisasi Tampilan Tabel**: Menyusun layout tabel dengan badge warna preview hex swatch, dropdown action menu (Edit, Delete), dan Bulk Action Bar yang seragam dengan Asset Statuses.

---

## Rincian Perubahan

### 1. Routes (`routes/web.php`) & `LookupController.php`
- **`routes/web.php`**:
  - Tambahkan route `POST` bulk-edit untuk seluruh admin lookup:
    - `admin/priorities/bulk-edit`
    - `admin/labels/bulk-edit`
    - `admin/sources/bulk-edit`
    - `admin/ticket-types/bulk-edit`
    - `admin/ticket-statuses/bulk-edit`
    - `admin/sla-statuses/bulk-edit`
- **`LookupController.php`**:
  - Tambahkan method `bulkEdit(Request $request)` untuk mengupdate `color` atau `is_active` massal pada `modelClass()`.
  - Dukung filter `is_active` pada query `index()`.

### 2. View `resources/views/admin/lookups/index.blade.php`
- **Quick Filter Tabs**: `[All Items] [Active] [Inactive]`.
- **Bulk Action Bar**:
  - Tombol **"Bulk Edit (Change Selected)"** membuka Pop-up Modal untuk memilih Status Keaktifan (Active/Inactive) dan/atau Color massal.
  - Tombol **"Delete Selected"** untuk hapus massal dengan konfirmasi.
- **Tabel & Kolom**:
  - Status Name (dikemas dalam `<x-ui.badge>` sesuai warnanya).
  - Code (formatted code tag).
  - Color (Hex swatch preview & hex string).
  - Sort Order & Active Status.
  - Actions Dropdown (`more-vertical` icon dengan menu Edit & Delete).
