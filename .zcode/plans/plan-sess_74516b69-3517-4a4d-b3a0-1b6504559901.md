# Implementation Plan: Bulk Edit & Layout Standardization for Asset & Ticket Statuses

## Overview
1. **Bulk Edit (Ganti Sekaligus)**: Menambahkan fitur **Bulk Edit (Mass Update)** pada halaman Asset Statuses agar pengguna dapat mengubah **Color** dan **Master Category** untuk beberapa status sekaligus secara simultan.
2. **Perbaikan & Penyelarasan Layout Index**: Menyelaraskan tampilan tabel Asset Statuses (`pages/master/statuses/index.blade.php`) dan Ticket Statuses (`admin/lookups/index.blade.php`) sesuai standar desain aplikasi (`docs/CRUD_STANDARDIZATION.md`), serta menambahkan **Master Category Filter Tabs** dan kolom **Master Category**.

---

## Rincian Perubahan

### 1. Route & Controller Updates (`StatusController.php` & `routes/web.php`)
- **Route (`routes/web.php`)**:
  - Tambahkan `Route::post('statuses/bulk-edit', [StatusController::class, 'bulkEdit'])->name('statuses.bulk-edit');`
- **Controller (`StatusController.php`)**:
  - Buat method `bulkEdit(Request $request)` untuk memproses pengubahan massal (`master_category_id` dan/atau `color`) pada ID status yang dipilih.
  - Tambahkan relasi `masterCategory` dan filter tab pada query `index()`.

### 2. Layout & UI Improvements (`pages/master/statuses/index.blade.php`)
- **Filter Tabs Master Category**:
  - Tampilkan tab Quick Filter di atas tabel: `[All Statuses] [IT Asset] [GA Asset] [IT Consumable] [GA Consumable] [IT Request] [GA Request]`.
- **Bulk Action Bar (Ganti Sekaligus & Hapus)**:
  - Tombol **"Bulk Edit (Change Color / Category)"** membuka modal Alpine.js untuk mengubah warna/kategori sekaligus.
  - Tombol **"Delete Selected"** untuk hapus massal dengan konfirmasi.
- **Kolom Tabel**:
  - Tambahkan kolom **Master Category** dengan badge yang jelas.
  - Rapikan kolom Status Label, Color (hex/preview badge), Assets Count, dan Actions.

### 3. Penyelarasan Layout Lookup/Ticket Statuses (`resources/views/admin/lookups/index.blade.php`)
- Pastikan tampilan tabel Ticket Statuses (Priorities, Statuses, SLA Statuses, Types) konsisten dengan format tabel standar aplikasi.
